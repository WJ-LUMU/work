# 80码生产数据自动整理工具

![Python](https://img.shields.io/badge/Python-3.8+-blue)
![License](https://img.shields.io/badge/License-MIT-green)

一个用于生产计划工作的 Excel 数据整理工具。自动整理生产日报数据，按照标准80码清单排序，识别新增数据，并进行数量核对。

## 🎯 功能特点

### 核心功能

- ✅ **按标准顺序整理** - 严格按照标准80码清单的顺序输出
- ✅ **自动合并重复** - 同一80码出现多次时自动求和
- ✅ **自动识别列** - 智能识别"80码"和"合计完成"等列
- ✅ **新增80码识别** - 自动找出标准清单中没有的新增80码
- ✅ **缺失80码填0** - 清单中有但报表中没有的80码自动填0
- ✅ **数量核对** - 自动核对原始数据与整理结果的总数是否一致
- ✅ **异常处理** - 完善的错误提示，方便定位问题

### 输出形式

生成 Excel 文件，包含三个工作表：

1. **按标准顺序整理** - 按清单顺序排列的完整数据
2. **新增80码** - 标准清单中不存在的新增80码
3. **核对结果** - 数量核对汇总

所有工作表都包含：
- 表头加粗、格式化
- 自动列宽调整
- 首行冻结
- 筛选功能开启
- 条纹行显示

## 🚀 使用方法

### 准备工作

在使用前，需要准备两个 Excel 文件：

#### 1. 标准80码清单文件

一个只包含80码的 Excel 文件，格式要求：
- 第一列为80码
- 按需要的顺序排列
- 可以有多行

示例��`标准80码清单.xlsx`
```
801001
801002
801003
801004
```

#### 2. 生产日报文件

生产部门提供的日报 Excel 文件，要求：
- 必须包含名称为"汇总"的工作表
- 包含"80码"（或"编码""物料编码"）列
- 包含"合计完成"（或"合计"）列

示例：`生产日报.xlsx`
```
汇总工作表中的数据：
80码    合计完成
801001  100
801003  50
801005  30
```

### 运行程序

#### 方式1：图形界面运行（推荐新手）

1. 打开文件管理器
2. 进入项目目录：`80-code-excel-organizer`
3. 双击 `main.py` 文件

或者在命令提示符中：
```bash
python main.py
```

#### 方式2：命令行运行

```bash
cd D:\project\80-code-excel-organizer
python main.py
```

### 交互步骤

程序运行后，会按步骤提示你：

```
============================================================
           80码生产数据自动整理工具 v1.0
============================================================

【步骤1】选择标准80码清单文件
------------------------------------------------------------

请输入Excel文件的完整路径（或直接拖入文件）：
> 
```

此时，你可以：
- 手动输入文件路径，例如 `D:\data\标准80码清单.xlsx`
- 或者直接拖入文件（将文件从文件管理器拖到命令窗口）

程序会验证文件是否存在，然后继续下一步。

重复此过程，分别选择：
1. 标准80码清单文件
2. 生产日报文件
3. 结果保存目录

完成后，程序自动处理数据并生成结果 Excel 文件。

## 📄 输出说明

### 输出文件名

生成的文件命名格式：`80码整理结果_20240115_143025.xlsx`

其中时间戳为程序运行时的日期和时间。

### 工作表说明

#### 工作表1：按标准顺序整理

| 列名 | 说明 |
|------|------|
| 序号 | 从1开始的行号 |
| 80码 | 标准清单中的80码，格式为文本 |
| 合计完成 | 对应的完成数量，不存在时为0 |
| 汇总表是否存在 | "是"或"否"，表示在原报表中是否出现过 |

#### 工作表2：新增80码

当标准清单中不存在的80码出现在报表中时，单独列出：

| 列名 | 说明 |
|------|------|
| 序号 | 从1开始的行号 |
| 80码 | 新增的80码 |
| 合计完成 | 对应的完成数量 |
| 备注 | 固定为"标准80码清单中不存在" |

如果没有新增80码，此工作表显示"未发现新增80码"。

#### 工作表3：核对结果

| 项目 | 说明 |
|------|------|
| 原始汇总表总计 | 原始生产日报中所有数据的总和 |
| 标准清单内总计 | 标准清单中包含的80码的总数 |
| 新增80码总计 | 新增80码的总数 |
| 整理后总计 | 标准清单内总计 + 新增80码总计 |
| 数量差异 | 原始汇总表总计 - 整理后总计 |
| 核对结果 | "核对一致"或"核对不一致" |

如果数量不一致，核对结果会显示为红色背景，需要检查问题。

## ❓ 常见问题

### Q1：无法找到"汇总"工作表

**问题描述**：程序报错"找不到名称为'汇总'的工作表"

**解决方法**：
1. 打开生产日报 Excel 文件
2. 检查是否有名称为"汇总"的工作表（工作表标签名称必须完全一致）
3. 如果工作表名称不同，例如"Summary"或"汇总表"，需要重命名为"汇总"
4. 重新运行程序

### Q2：80码被读取为科学计数法

**问题描述**：80码"80962510809"被显示为"8.09625E+10"或"80962510809.0"

**解决方法**：
- 程序会自动处理这种情况，无需手动干预
- 如果问题仍然存在，请检查原始 Excel 文件中该列的格式是否为"文本"格式
- 解决方法：在 Excel 中选中该列，右键 → 格式单元格 → 数字 → 选择"文本"

### Q3：程序找不到"合计完成"列

**问题描述**：程序报错"找不到数量列"

**解决方法**：
1. 打开生产日报文件，检查是否有以下列名之一：
   - "合计完成" （优先）
   - "合计"
   - "数量"
   - "qty"
   - "quantity"

2. 如果有，请确保列名完全一致（包括空格）
3. 如果没有，请手动添加一列并命名为"合计完成"

### Q4：程序运行后找不到输出文件

**问题描述**：程序显示完成，但找不到结果文件

**解决方法**：
1. 检查你指定的保存目录是否正确
2. 打开文件管理器，进入该目录
3. 按时间排序，查找最新生成的 `.xlsx` 文件
4. 也可以直接在程序目录的"结果"文件夹中查找

### Q5：数量核对不一致

**问题描述**：输出文件的核对结果显示"核对不一致"

**解决方法**：
1. 打开输出文件，查看"核对结果"工作表
2. 检查"数量差异"是多少
3. 可能的原因：
   - 原始报表中有不能识别的80码或数量（查看是否有警告提示）
   - 原始报表中有合计行，需要手动删除
   - 有的行的数量列为文本而非数字

4. 修正原始数据后重新运行程序

### Q6：如何处理原始报表中的总行

**问题描述**：生产日报最后一行是"合计"，会被当作80码处理

**解决方法**：
在运行程序前，手动删除原始报表中的合计行、页脚等非数据行。

## 📁 项目结构

```
80-code-excel-organizer/
│
├── main.py                          # 主程序入口
│   ├─ 获取用户输入
│   ├─ 调用各模块
│   └─ 显示处理结果
│
├── src/                             # 源代码包
│   ├── __init__.py
│   │
│   ├── excel_reader.py              # Excel读取模块
│   │   ├─ read_standard_codes()     # 读取标准80码清单
│   │   └─ read_report_sheet()       # 读取生产日报
│   │
│   ├── data_processor.py            # 数据处理核心模块
│   │   ├─ process()                 # 主处理函数
│   │   ├─ _merge_duplicates()       # 合并重复80码
│   │   ├─ _arrange_by_standard()    # 按顺序排列
│   │   └─ _find_new_codes()         # 识别新增80码
│   │
│   └── excel_exporter.py            # Excel导出模块
│       ├─ export()                  # 导出主函数
│       ├─ _fill_standard_sheet()    # 填充第1个工作表
│       ├─ _fill_new_codes_sheet()   # 填充第2个工作表
│       └─ _fill_summary_sheet()     # 填充第3个工作表
│
├── examples/                        # 示例数据
│   ├── 示例标准清单.xlsx
│   └── 示例生产日报.xlsx
│
├── templates/                       # 模板文件（扩展用）
│   └── 标准80码清单模板.xlsx
│
├── requirements.txt                 # 依赖列表
├── README.md                        # 项目说明
├── .gitignore                       # Git忽略配置
└── LICENSE                          # 开源协议 (MIT)
```

### 各文件说明

| 文件/目录 | 用途 |
|---------|------|
| `main.py` | 程序入口，包含命令行交互 |
| `src/excel_reader.py` | 负责读取Excel文件 |
| `src/data_processor.py` | 负责数据处理逻辑 |
| `src/excel_exporter.py` | 负责导出结果到Excel |
| `examples/` | 包含测试用的示例数据 |
| `requirements.txt` | Python依赖列表 |
| `README.md` | 项目文档（本文件） |
